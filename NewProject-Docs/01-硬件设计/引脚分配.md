# 引脚分配

## 概述

CC2530F256 共有 3 个 8 位 GPIO 端口（P0、P1、P2），本项目引脚分配如下：

| 功能分组 | 引脚范围 | 说明 |
|----------|----------|------|
| LED 指示 | P0_0 ~ P0_3 | 4 路 LED，反逻辑，直接 GPIO 输出 |
| 触摸输入 | P0_4 ~ P0_7 | WTC6106BSI 输出，低电平=触摸 |
| 继电器控制 | P1_0, P1_2, P1_6, P2_0 | 4 路继电器，低电平触发吸合 |
| S1 配网/复位按键 | P1_3 | 低电平有效，复用触摸轮询检测 |

> **重要**: 用户需求文档中曾将触摸输入标注为 P1_0~P1_3，该描述与实际代码不符。实际触摸输入为 **P0_4~P0_7**，继电器为 P1_0/P1_2/P1_6/P2_0，S1 按键为 P1_3。本文档以固件源码为准。

## 引脚分配总表

| 功能 | CC2530 引脚 | 方向 | 初始状态 | 逻辑说明 |
|------|-------------|------|----------|----------|
| LED 1 | P0_0 | 输出 | HIGH（亮） | 反逻辑：继电器 OFF → LED 亮 |
| LED 2 | P0_1 | 输出 | HIGH（亮） | 反逻辑 |
| LED 3 | P0_2 | 输出 | HIGH（亮） | 反逻辑 |
| LED 4 | P0_3 | 输出 | HIGH（亮） | 反逻辑 |
| 触摸输入 1 | P0_4 | 输入 | 上拉（高） | 低电平有效（触摸拉低） |
| 触摸输入 2 | P0_5 | 输入 | 上拉（高） | 低电平有效 |
| 触摸输入 3 | P0_6 | 输入 | 上拉（高） | 低电平有效 |
| 触摸输入 4 | P0_7 | 输入 | 上拉（高） | 低电平有效 |
| 继电器 1 | P1_0 | 输出 | HIGH（断开） | 低电平触发吸合 |
| 继电器 2 | P1_2 | 输出 | HIGH（断开） | 低电平触发吸合 |
| 继电器 3 | P1_6 | 输出 | HIGH（断开） | 低电平触发吸合 |
| 继电器 4 | P2_0 | 输出 | HIGH（断开） | 低电平触发吸合 |
| S1 配网/复位按键 | P1_3 | 输入 | 上拉（高） | 低电平有效 |

> **上电初始状态**: Pull-up 使 GPIO 默认 HIGH → 继电器全部断开（OFF）+ LED 全部亮。对应 Zigbee 报文 `OnOff: Off`。

## 引脚逻辑详解

### LED 与继电器联动（反逻辑）

| 逻辑状态 | Zigbee 报文 | 继电器 GPIO | LED GPIO | 继电器物理 | LED 物理 |
|---------|------------|-------------|----------|-----------|---------|
| **OFF** | `OnOff: Off` | HIGH | LOW（写 0） | 断开 | **亮** |
| **ON** | `OnOff: On` | LOW（写 0） | HIGH（写 1） | 吸合 | **灭** |

> **反逻辑设计意图**: LED 与继电器状态相反，用于在黑暗环境中标识开关位置（断开时灯亮，便于用户找到开关）。

### 继电器输出逻辑

```c
// 继电器: ON=低电平触发吸合, OFF=高电平断开
P1_0 = on ? 0 : 1;   // 继电器1
P1_2 = on ? 0 : 1;   // 继电器2
P1_6 = on ? 0 : 1;   // 继电器3
P2_0 = on ? 0 : 1;   // 继电器4
```

### LED 输出逻辑（反逻辑）

```c
// LED: 亮=写0, 灭=1 (反逻辑)
// 继电器ON -> LED灭, 继电器OFF -> LED亮
uint8 val = on ? 0 : 1;   // on=TRUE(亮) -> 写0; on=FALSE(灭) -> 写1
switch (idx)
{
  case 0: P0_0 = val; break;
  case 1: P0_1 = val; break;
  case 2: P0_2 = val; break;
  case 3: P0_3 = val; break;
}
```

## HAL_KEY 冲突警告

> **必须设置 `HAL_KEY=FALSE`**，否则 `hal_key.c` 会干扰 P2.0（继电器 4）和 P0.6（触摸输入 3）。

| 冲突引脚 | 本项目功能 | hal_key.c 默认占用 | 后果 |
|----------|-----------|-------------------|------|
| P2.0 | 继电器 4 控制 | HAL_KEY SW5 | 继电器 4 异常动作 |
| P0.6 | 触摸输入 3 | HAL_KEY SW4 | 触摸 3 误触发 |

### 配置方法

在 IAR 工程文件 `HGZBSwitch.ewp` 中已配置编译选项：

```
HAL_KEY=FALSE
```

> 禁用 HAL_KEY 后，S1 按键检测改由应用层在触摸轮询函数 `zclSampleSw_ProcessTouchPoll()` 中直接读取 `P1_3` 引脚电平实现，不依赖 HAL 层按键框架。

## S1 按键检测机制

S1 按键（P1_3）**复用触摸轮询检测**，在 `zclSampleSw_ProcessTouchPoll()` 中与触摸输入一起轮询：

| 参数 | 值 | 说明 |
|------|-----|------|
| 引脚 | P1_3 | 低电平有效 |
| 轮询周期 | 50 ms | `TOUCH_POLL_INTERVAL_MS` |
| 长按阈值 | 100 次 | `S1_RESET_THRESHOLD` = 100 × 50ms = **5 秒** |
| 短按动作 | 配网 | 由 BDB 层处理 |
| 长按 5 秒动作 | 工厂复位 | `bdb_resetLocalAction()` |

### S1 长按检测代码

```c
// S1长按检测 (P1_3, 低电平有效)
if (!P1_3)
{
  s1HoldCount++;
  if (s1HoldCount >= S1_RESET_THRESHOLD)   // 100 * 50ms = 5秒
  {
    s1HoldCount = 0;
    // 启动LED闪烁状态机, 闪烁结束后执行复位
    zclSampleSw_StartResetBlink();
    // 停止触摸轮询, 避免闪烁期间被干扰
    osal_stop_timerEx(zclSampleSw_TaskID, SAMPLESW_TOUCH_POLL_EVT);
    return;
  }
}
else
{
  s1HoldCount = 0;   // 松开重置计数
}
```

## 引脚初始化代码

### 位掩码宏定义

```c
// 继电器引脚位掩码 (P1口: P1_0/P1_2/P1_6, P2口: P2_0)
#define RELAY_P1_BV               (BV(0) | BV(2) | BV(6))
#define RELAY_P2_BV               (BV(0))
// 触摸输入引脚位掩码 (P0_4~P0_7)
#define TOUCH_INPUT_BV            (BV(4) | BV(5) | BV(6) | BV(7))
```

### InitGpio 函数（zcl_samplesw.c）

```c
/*********************************************************************
 * @fn      zclSampleSw_InitGpio
 *
 * @brief   初始化继电器/LED/触摸引脚的GPIO方向与初始电平
 *          继电器(P1_0/P1_2/P1_6/P2_0): 输出, 默认高电平(继电器断开)
 *          LED(P0_0~P0_3): 已由HalLedInit配置为输出, 这里同步为继电器状态
 *          触摸(P0_4~P0_7): 输入, 上拉(CC2530 P0口默认上拉)
 * @return  none
 */
void zclSampleSw_InitGpio(void)
{
  // 继电器引脚设为GPIO功能并配置为输出
  P1SEL &= ~RELAY_P1_BV;        // P1_0/P1_2/P1_6 选为GPIO
  P2SEL &= ~RELAY_P2_BV;        // P2_0 选为GPIO
  P1DIR |= RELAY_P1_BV;         // 设为输出
  P2DIR |= RELAY_P2_BV;         // 设为输出

  // 触摸输入引脚设为GPIO功能并配置为输入(默认上拉)
  // WTC6106BSI: 未触摸=高电平, 触摸=低电平(开漏输出, 需上拉)
  P0SEL &= ~TOUCH_INPUT_BV;     // P0_4~P0_7 选为GPIO
  P0DIR &= ~TOUCH_INPUT_BV;     // 设为输入

  touchStableState = 0;
}
```

> **LED 初始化说明**: LED 引脚（P0_0~P0_3）的方向配置由 `HalLedInit()` 完成（HAL 层），`zclSampleSw_InitGpio()` 不重复配置 LED 方向，仅通过 `zclSampleSw_UpdateAllRelayOutputs()` 将 LED 状态同步为继电器状态。

### 调用顺序

```c
// zclSampleSw_Init() 中的调用顺序
zclSampleSw_NvInit();              // 1. 初始化NV项
zclSampleSw_NvLoadPowerOnState();  // 2. 按startUpOnOff策略恢复断电前状态
zclSampleSw_InitGpio();            // 3. 初始化继电器/LED/触摸GPIO
zclSampleSw_UpdateAllRelayOutputs(); // 4. 根据恢复后的状态应用GPIO输出
osal_start_timerEx(zclSampleSw_TaskID, SAMPLESW_TOUCH_POLL_EVT, TOUCH_POLL_INTERVAL_MS); // 5. 启动触摸轮询
```

> **调用顺序关键**: `zclSampleSw_InitGpio()` 必须在 `zclSampleSw_NvLoadPowerOnState()` 之后、`zclSampleSw_UpdateAllRelayOutputs()` 之前调用，确保 GPIO 输出与断电恢复后的状态一致。
