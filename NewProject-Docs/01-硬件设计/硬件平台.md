# 硬件平台

## 概述

本项目为基于 CC2530F256 的 4 路 Zigbee 智能墙壁开关，采用 86 型开关外壳（借壳 HGZB-4S），通过 WTC6106BSI 触摸芯片实现本地触摸控制，4 路继电器实现灯具开关，常供电设计，作为 Router 角色加入 Zigbee 网络。

## 核心元器件

### 主控芯片

| 项目 | 参数 |
|------|------|
| 型号 | CC2530F256RHAR |
| 厂商 | Texas Instruments |
| 内核 | 增强型 8051 |
| Flash | 256 KB |
| RAM | 8 KB |
| 射频 | 2.4 GHz Zigbee（集成 RF 收发器） |
| 协议栈 | Z-Stack 3.0.2 |
| 封装 | QFN40 |

> **说明**: CC2530F256 为单芯片 Zigbee SoC 方案，MCU 与射频集成于同一芯片。**无 CC2592 等外部 PA（功率放大器）芯片**，射频信号由 CC2530 裸片直出。

### 触摸芯片

| 项目 | 参数 |
|------|------|
| 型号 | WTC6106BSI |
| 通道数 | 4 路有效触摸输入（芯片支持 6 路，本项目使用 OUT0~OUT3） |
| 内部架构 | 16bit CDC（电容数字转换器）+ RISC 处理器 |
| 输出信号 | 持续电平（非脉冲） |
| 输出极性 | **固定极性**：未触摸=高电平，触摸=低电平（开漏输出，需上拉） |
| 响应延迟 | 50~150 ms |
| 极性配置 | 无需配置，硬件固定 |

> **信号特征**: WTC6106BSI 内置 16bit CDC + RISC 处理器，直接输出高低电平指示按键动作。触摸时输出低电平（有效），松开恢复高电平。CC2530 通过轮询检测电平变化即可识别触摸事件，无需 SPI/I2C 通信。
>
> **极性固定**: 未触摸=高电平，触摸=低电平。固件层无需也无法配置输出极性。

### 继电器

| 项目 | 参数 |
|------|------|
| 路数 | 4 路 |
| 触发方式 | 低电平触发吸合（GPIO 输出低=ON，输出高=OFF） |
| 应用场景 | 86 型墙壁开关，控制 4 路灯具 |
| 初始状态 | 上电默认断开（OFF），由 startUpOnOff 策略决定后续状态 |

### LED 指示灯

| 项目 | 参数 |
|------|------|
| 路数 | 4 路（对应 4 路继电器状态） |
| 引脚 | P0_0 ~ P0_3 |
| 逻辑 | 反逻辑：继电器 OFF → LED 亮（指示开关位置）；继电器 ON → LED 灭 |
| 型号 | 0603 贴片 LED |
| 调光能力 | **无 PWM 调光**，直接 GPIO 输出，亮度 100% |

> **PWM 说明**: CC2530 硬件定时器理论可用于 PWM 调光，但早期版本（v1.0.6~v1.0.7）实现的软件 PWM（5ms 周期定时器）持续占用 MCU 资源，影响 Zigbee 协议栈时序，导致 RF 信号不稳定。v1.0.8 起完全移除 PWM 调光功能，LED 控制恢复直接写 GPIO，亮度固定 100%。

## 供电设计

| 项目 | 参数 |
|------|------|
| 供电方式 | 常供电（非电池） |
| 取电来源 | 86 型墙壁开关底盒（市电接入） |
| 电源类型 | 单相交流电（PowerSource = MAINS_1_PHASE） |
| 工作电压 | 3.3V DC（内部稳压） |

> **常供电优势**: 墙壁开关长期通电，不会因断电导致路由表丢失，适合作为 Zigbee Router（路由器）中继网络信号。

## 射频参数

| 项目 | 参数 |
|------|------|
| 发射功率 | 4 dBm（`TX_PWR_PLUS_4`） |
| PA 芯片 | 无（CC2530 裸片直出） |
| 功率配置时机 | `bdb_StartCommissioning()` 之前调用 `ZMacSetTransmitPower(TX_PWR_PLUS_4)` |

> **功率选型结论**:
> - 7 dBm：导致 RF 不稳定（信号归零）
> - 5 dBm：无改善
> - **4 dBm + 移除 PWM 调光**：最佳配置，信号稳定

## 调试与烧录接口

### J2 — 调试/烧录接口（5Pin）

| 引脚 | 功能 | 说明 |
|------|------|------|
| 1 | GND | 地 |
| 2 | RST | 复位 |
| 3 | DC | 调试时钟 |
| 4 | DD | 调试数据 |
| 5 | 3V3 | 电源 |

> **烧录方式**: 通过 CC Debugger 经 DC/DD 引脚烧录，本项目使用 CCLoader + ESP8266 无线烧录方案。
