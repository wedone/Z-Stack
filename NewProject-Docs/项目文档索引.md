## ⚠️ 开发规则：设备内交互必须参考 dev 代码

linxee 分支开发时，必须遵循以下规则避免重复 dev 已解决的问题：

### 1. 设备内交互（直接参考 dev 代码）

GPIO 初始化、LED 控制、继电器联动、触摸检测、S1 复位 LED 闪烁、配网 LED 慢闪等**本地交互**功能：
- 不涉及网络通信，**不受路由问题影响**
- **必须先读 [dev 设备内交互参考代码](05-经验教训/dev%20设备内交互参考代码.md)**，直接参考 dev 最终代码
- 不要凭文档描述重新实现，避免遗漏已验证的细节（如 LED 反逻辑、配网慢闪互斥、防御性刷新等）

### 2. 对外通信（谨慎评估）

ZCL Report、入网流程、BDB commissioning 等**网络通信**功能：
- 可能受 PTVO 路由问题影响，需谨慎评估
- 参考 dev 实现但需独立验证

### 3. 区分原则

| 类别 | 范围 | 是否受路由影响 | 处理方式 |
|------|------|---------------|----------|
| 设备内交互 | GPIO/LED/触摸/继电器/S1复位 | ❌ 不受影响 | 直接参考 dev 代码 |
| 对外通信 | ZCL Report/入网/BDB | ⚠️ 可能受影响 | 谨慎评估+独立验证 |

## 关键技术决策速查

| 决策 | 值 | 原因 |
|------|-----|------|
| 触摸检测方案 | 直接低电平读取 | WTC6106BSI电平漂移，自适应基线不可用 |
| 触摸轮询周期 | 50ms | 接近WTC6106BSI硬件响应极限 |
| 防抖次数 | 2次 | 100ms防抖窗口 |
| S1长按复位 | 5秒 (100×50ms) | 复用触摸轮询计数 |
| startUpOnOff | 4路独立uint8数组 | 单变量会互相覆盖 |
| NV ID (继电器状态) | 0x0F10 | 避开系统区和ZNP保留区 |
| NV ID (startUpOnOff) | 0x0F12 | 避开旧ID 0x0F11 |
| NV写入策略 | 延迟5秒 + 对比写入 | Flash寿命优化 |
| genBasic端点 | EP11 | EP8与INPUT4冲突 |
| LED控制 | 直接GPIO (无PWM) | 软件PWM干扰MAC时序 |
| TX功率 | 4 dBm | 7dBm不稳定，0dBm偏低 |
| ZCL命令后上报 | 不上报 | ZCL层自动发DefaultRsp，堆仅3072字节 |
| 触摸后上报 | 上报 | z2m不知道本地触摸事件 |
| 入网后上报 | 立即上报所有4路 | 状态同步 |
| 周期性上报 | 不使用 | 触发z2m无意义action事件 |
| HAL_KEY | FALSE | 避免P2.0/P0.6引脚冲突 |
| BDB commissioning | 按NV状态选择 | mode=0x00不设置任何mode位 |
| 配网LED | 1Hz慢闪, 5分钟超时 | IKEA风格 |
| 复位LED | 3次闪烁, 300ms亮/灭 | 自定义状态机，不用HalLedBlink |
