# 功能清单

## 概述

本项目为基于 CC2530F256 + Z-Stack 3.0.2 的 4 路 Zigbee 智能墙壁开关固件，借壳 HGZB-4S 接入 Zigbee2MQTT（Z2M）/ Home Assistant（HA），实现远程控制、本地触摸控制、断电记忆、配网提示、工厂复位等功能。

## 功能列表

### 1. 远程开关控制

| 功能 | 说明 |
|------|------|
| 4 路开关控制 | Z2M/HA 远程控制 4 路继电器开关 |
| 端点映射 | EP1~EP4 对应 Z2M 的 l1~l4 |
| ZCL 簇 | genOnOff（0x0006） |
| 支持命令 | On / Off / Toggle |
| 响应动作 | 继电器动作 + LED 反相 + ZCL 状态上报 |

### 2. 本地触摸控制

| 功能 | 说明 |
|------|------|
| 4 路触摸输入 | WTC6106BSI 触摸芯片，本地触摸切换继电器 |
| 触摸芯片 | WTC6106BSI（固定极性，低电平=触摸） |
| 轮询周期 | 50 ms（`TOUCH_POLL_INTERVAL_MS`） |
| 软件防抖 | 连续 2 次确认（100 ms，`TOUCH_DEBOUNCE_COUNTS`） |
| 触发方式 | 上升沿（未触摸→触摸）触发一次翻转，长按不重复触发 |
| 联动动作 | 继电器翻转 + LED 反相 + ZCL OnOff 状态上报 |

### 3. 断电恢复（startUpOnOff）

| 功能 | 说明 |
|------|------|
| 4 路独立策略 | 每路继电器独立配置 startUpOnOff，互不影响 |
| 配置选项 | off / on / toggle / previous |
| ZCL 属性 | startUpOnOff（0x4003），enum8，读写权限 |
| NV 持久化 | NV ID 0x0F12，uint8[4] 数组 |
| 默认值 | PREVIOUS（0xFF，恢复断电前状态） |
| 写入策略 | 延迟 5 秒合并写入（`SAMPLESW_NV_SAVE_DELAY_MS`），减少 Flash 磨损 |

| 配置值 | 名称 | 行为 |
|--------|------|------|
| 0x00 | OFF | 上电后该路为 OFF |
| 0x01 | ON | 上电后该路为 ON |
| 0x02 | TOGGLE | 上电后翻转断电前状态 |
| 0xFF | PREVIOUS | 恢复断电前状态（默认） |

### 4. S1 长按工厂复位

| 功能 | 说明 |
|------|------|
| 触发条件 | S1 按键（P1_3）长按 5 秒 |
| 检测方式 | 复用触摸轮询，`S1_RESET_THRESHOLD` = 100 次 × 50 ms = 5 秒 |
| 复位动作 | `bdb_resetLocalAction()` |
| 复位流程 | Basic Reset（重置 ZCL 属性）→ BDB Reset to FN（发送 NLME_LeaveReq）→ 刷新继电器/LED 状态 |

### 5. 配网 LED 提示

| 功能 | 说明 |
|------|------|
| 配网中提示 | LED1 以 1 Hz 慢闪（500ms 亮 / 500ms 灭） |
| 启动时机 | `zclSampleSw_Init()` 末尾，设备未入网时启动 |
| 停止条件 1 | ZDO 状态变为 `DEV_ROUTER`（入网成功） |
| 停止条件 2 | 超时 5 分钟（`SAMPLESW_PAIRING_TIMEOUT_MS` = 5 × 60 × 1000 ms） |
| 作用范围 | 仅操作 LED1（P0_0），不影响继电器状态和其他 LED |

### 6. 复位 LED 提示

| 功能 | 说明 |
|------|------|
| 触发条件 | S1 长按 5 秒达到阈值 |
| 闪烁方式 | LED1 闪烁 3 次（300ms 亮 / 300ms 灭，共 1.8 秒） |
| 闪烁参数 | `RESET_BLINK_TOTAL_COUNT` = 6（3 次闪烁 = 6 次状态切换） |
| 闪烁周期 | `RESET_BLINK_PERIOD_MS` = 300 ms |
| 执行顺序 | 闪烁完成后执行复位流程（Basic Reset + bdb_resetLocalAction） |
| 实现方式 | 直接 GPIO 操作（替代 `HalLedBlink`，避免 `HalLedState` 不一致） |

### 7. 状态同步

| 功能 | 说明 |
|------|------|
| 触摸操作上报 | 触摸翻转后立即上报单路 ZCL OnOff 状态 |
| ZCL 命令响应上报 | 远程命令处理后立即上报单路状态 |
| 入网立即上报 | ZDO 状态变为 `DEV_ROUTER` 时，立即上报所有 4 路状态 |
| 周期性上报 | 每 30 秒（`STATE_REPORT_INTERVAL_MS` = 30000 ms）上报所有 4 路状态 |
| 上报函数 | `zclSampleSw_ReportOnOffState(idx)` / `zclSampleSw_ReportAllOnOffState()` |
| 依赖宏 | `ZCL_REPORTING_DEVICE`（启用 `zcl_SendReportCmd`） |

> **双机制保证 Z2M 状态一致性**：
> - **入网立即上报**：修复断电恢复后 Z2M 不同步（BUG-007）
> - **周期性上报**：修复信号不好时单次上报丢失导致长期不同步（BUG-008）

### 8. TX 功率配置

| 功能 | 说明 |
|------|------|
| 发射功率 | 4 dBm（`TX_PWR_PLUS_4`） |
| 配置函数 | `ZMacSetTransmitPower(TX_PWR_PLUS_4)` |
| 配置时机 | `bdb_StartCommissioning()` 之前，确保入网时即使用设置后的功率 |
| 选型结论 | 7 dBm 导致 RF 不稳定，5 dBm 无改善，**4 dBm 为最佳配置** |

### 9. 借壳 HGZB-4S

| 功能 | 说明 |
|------|------|
| 借壳型号 | HGZB-4S（Nue / 3A） |
| ModelId | `LXN-4S27LX1.0`（借壳匹配键，不可改） |
| Z2M 接入 | 内置匹配，**免 External Converter** |
| 端点映射 | `l1:1, l2:2, l3:3, l4:4` |
| powerOnBehavior | 默认启用，Z2M 页面直接显示 `Power-on behavior` 配置项 |
