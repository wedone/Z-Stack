## 三、ESP32 GPIO 引脚分配详解

> 数据来源：ESP-HOME 配置文件 `uzg01-zigbee.yaml`，为实际硬件引脚定义

### 1. 以太网 PHY (LAN8720) — RMII 接口

| ESP32 GPIO | 信号 | LAN8720 引脚 | 说明 |
|-----------|------|-------------|------|
| **GPIO23** | EMAC_MDC | MDC | MDIO 管理接口时钟 |
| **GPIO18** | EMAC_MDIO | MDIO | MDIO 管理接口数据 |
| **GPIO17** | EMAC_TX_CLK | REF_CLK / XTAL1 | 50MHz 参考时钟输出 (GPIO17_OUT 模式) |
| **GPIO05** | — | nINT / PWRDOWN | PHY 电源控制/中断 |
| — | — | PHYAD0 | PHY 地址 = **0** (通过下拉电阻配置) |

**RMII 数据引脚 (标准 ESP32 EMAC 引脚)**：

| ESP32 GPIO | 信号 | 方向 |
|-----------|------|------|
| GPIO19 | EMAC_TXD0 | 输出 |
| GPIO22 | EMAC_TXD1 | 输出 |
| GPIO21 | EMAC_TX_EN | 输出 |
| GPIO25 | EMAC_RXD0 | 输入 |
| GPIO26 | EMAC_RXD1 | 输入 |
| GPIO27 | EMAC_RX_DV (CRS_DV) | 输入 |

### 2. Zigbee SoC (CC2652P7) — UART 串口

| ESP32 GPIO | 信号 | CC2652P 引脚 | 说明 |
|-----------|------|-------------|------|
| **GPIO04** | UART_TXD | DIOx (RX) | ESP32 发 → CC2652 收 |
| **GPIO36** | UART_RXD | DIOx (TX) | ESP32 收 ← CC2652 发 |
| **GPIO16** | zRST | RESET_n | CC2652 复位（低有效，inverted） |
| **GPIO32** | zBSL / BSL | DIOx (BSL) | CC2652 Flash 模式（低有效，inverted） |

**串口参数**：
- 波特率：115200
- 流控：无（software flow control）
- 协议：ZNP (Zigbee Network Processor)

### 3. USB 转串口 (CH340C)

| ESP32 信号 | CH340C 引脚 | 说明 |
|-----------|------------|------|
| U0TXD (GPIO1) | RXD | ESP32 发 → USB 收 |
| U0RXD (GPIO3) | TXD | ESP32 收 ← USB 发 |
| EN | DTR → 三极管 | 自动下载：拉低 EN（复位） |
| GPIO0 | RTS → 三极管 | 自动下载：拉低 GPIO0（下载模式） |

### 4. LED 指示灯（共 3 个）

| 序号 | LED | 颜色 | 控制源 | 功能 |
|-----|-----|------|--------|------|
| LED1 | 蓝灯 | 蓝色 | ESP32 GPIO14 | 电源指示灯（常亮） |
| LED2 | 红灯 | 红色 | ESP32 GPIO12 | 模式指示灯（USB 模式亮，LAN 模式灭） |
| LED3 | 黄灯 | 黄色 | CC2652P / 网络 | Z2M 连接状态 / 网络状态 |

> **说明**：黄灯具体由谁控制待确认，可能是 CC2652P 直接控制（Zigbee 网络状态），也可能是 LAN8720 的网络活动 LED。

### 5. 按键与模式切换

| ESP32 GPIO | 功能 | 说明 |
|-----------|------|------|
| **GPIO35** | 用户按键 | 多功能按键（inverted，低有效） |
| **GPIO33** | 模式选择 | 模式开关控制：ON=USB 模式，OFF=LAN 模式 |

## 四、"左中那个模块" — LAN8720A 详解

### 为什么是 LAN8720A？

**三重验证**：

1. **产品页面明确说明**："Main chips used are **ESP32, LAN8720, CH340C**"
2. **功能推断**：ESP32 内置 EMAC（以太网 MAC），需外接 PHY 芯片才能接网线。市场上 ESP32 + 百兆以太网的标准 PHY 就是 **LAN8720**
3. **PCB 位置匹配**：左中小芯片位于 RJ45 网口下方、网络变压器旁，正好是 PHY 芯片的典型位置

### LAN8720A 基本信息

| 项 | 值 |
|----|-----|
| 型号 | LAN8720A（Microchip / SMSC） |
| 功能 | 10/100Mbps 以太网物理层 (PHY) 收发器 |
| 接口 | RMII（Reduced Media Independent Interface） |
| 封装 | QFN-24 (4x4mm) |
| 电压 | 3.3V 单电源 |
| 典型应用 | ESP32 / STM32 等 MCU 外接以太网 |

### 与 ESP32 的连接（RMII 接口）

原理图第 7 页 ESP32 侧的 `EMAC_xxx` 信号就是 RMII 接口，连接到 LAN8720：

| ESP32 信号 | LAN8720 引脚 | 说明 |
|-----------|-------------|------|
| EMAC_TXD0 | TXD0 | 发送数据位 0 |
| EMAC_TXD1 | TXD1 | 发送数据位 1 |
| EMAC_TX_EN | TXEN | 发送使能 |
| EMAC_TX_CLK | REF_CLK / XTAL1 | 发送时钟 (50MHz) |
| EMAC_RXD0 | RXD0 | 接收数据位 0 |
| EMAC_RXD1 | RXD1 | 接收数据位 1 |
| EMAC_RX_ER | RXER | 接收错误 |
| EMAC_RX_DV | CRS_DV | 接收数据有效 |
| EMAC_MDC | MDC | MDIO 管理接口时钟 |
| EMAC_MDIO | MDIO | MDIO 管理接口数据 |
| EMAC_TX_ER | — | 发送错误 (可选，常接地) |

### LAN8720 周边电路

1. **50MHz 晶振**：给 PHY 提供参考时钟（原理图第 7 页 X1 位置，25MHz 或 50MHz 取决于配置）
2. **PHY 地址配置**：通过上拉/下拉电阻设置 PHY Address（通常为 0 或 1）
3. **复位电路**：由 ESP32 GPIO 控制 PHY 复位
4. **状态指示 LED**：LINK/ACT/SPEED 等 LED（原理图第 6 页 NET_LED 附近）

## 五、其他模块详解

### 1. 主控制器 — ESP32-WROOM-32

| 项 | 值 |
|----|-----|
| 位置 | 原理图第 7 页右中上 |
| 功能 | 主应用处理器 + WiFi + 蓝牙 |
| 接口 | RMII (接 LAN8720)、UART0 (接 CH340C)、UART1 (接 CC2652P)、GPIO、SDIO |

**关键外围**：
- 3.3V 供电去耦电容
- 40MHz 晶振
- 自动下载电路 (CH340C 的 DTR/RTS → 双三极管 → EN/GPIO0)
- BOOT 按钮 + RESET 按钮
- U.FL 天线座 (底部)

### 2. Zigbee SoC — CC2652P7

| 项 | 值 |
|----|-----|
| 位置 | 原理图第 2 页左中大芯片 |
| 功能 | Zigbee/Thread/BLE 多协议 SoC，+20dBm 内置 PA |
| 前代型号 | CC2652P2 (v0.1 版) |
| 与 ESP32 连接 | UART 串口 (TX/RX) |

**关键外围**：
- RF 输出 π 型匹配网络 (原理图右侧)
- 24/48MHz 晶振
- 32.768kHz 低频晶振
- 调试接口 (JTAG/SWD)
- 与 ESP32 的串口流控 (可选)

> **关于 D0-D15 / AD0-AD7 的说明**：原理图上的标识可能是设计人员自定义的网络名，不是芯片官方命名。CC2652 官方命名为 DIO0~DIO31，这些 D0-D15 只是连接到 ESP32 的数字 IO 的简写。

### 3. USB 转串口 — CH340C

| 项 | 值 |
|----|-----|
| 位置 | 原理图第 3 页中下 |
| 功能 | USB ↔ UART 转换，用于 ESP32 烧录和调试 |
| 实际 BOM | CH340C (WCH) |
| 原理图标注 | 可能标注为 CP2102 (参考设计遗留) |

**关键外围**：
- USB-C 接口 (原理图第 3 页左下 U8)
- USB ESD 保护二极管
- 自动下载电路 (DTR/RTS → 三极管 → ESP32 EN/GPIO0)
- 状态 LED

### 4. 网络变压器 — HX1188NLT

| 项 | 值 |
|----|-----|
| 位置 | 原理图第 6 页右中 |
| 品牌 | HanRun (汉仁) |
| 功能 | 百兆以太网隔离变压器 |
| 左侧 | 接 LAN8720 (RX+/RX-/TX+/TX-) |

## 八、验证要点（如何确认 LAN8720）

如果你手上有实物，可以通过以下方式验证：

1. **看丝印**：左中小芯片上的丝印，LAN8720A 的丝印通常是 `LAN8720A` 或缩写
2. **查封装**：QFN-24 4x4mm，24 脚，对比实物
3. **测电路**：
   - 找 25MHz 或 50MHz 晶振 → 旁边就是 PHY
   - 找 RJ45 网口差分线 → 经过网络变压器 → 连到 PHY
   - 找 ESP32 的 GPIO16-GPIO19 等 RMII 引脚 → 连到 PHY

## 十、电源电路详解

### 供电方式

UZG-01 支持两种供电方式：
1. **USB-C 供电**：5V 输入
2. **PoE 供电**：802.3af 标准，48V 网线供电

### 电源架构

```
PoE 48V ──→ PoE 受电模块 ──→ 5V ──┐
                                    ├──→ DCDC 降压 ──→ 3.3V ──→ 主电路
USB-C 5V ──────────────────────────┘
```

### 主要电源器件（参考同系列 BOM 推断）

| 器件 | 型号 | 功能 | 封装 |
|-----|------|------|------|
| U4 | **AMS1117-3.3** | 3.3V LDO 稳压器 | SOT-223 |
| — | MP2359 / 类似 | DCDC 降压（5V→3.3V，大电流） | SOT23-6 |
| — | PoE 受电芯片 | 802.3af PoE PD 接口 | — |

### 3.3V 电源轨负载

- ESP32-WROOM-32：约 100-200mA（峰值更高）
- CC2652P7：约 30-50mA（发射时 +20dBm 可达 ~100mA）
- LAN8720A：约 50-80mA
- CH340C：约 10-20mA
- LED、电阻等：约 10-30mA

**总功耗估算**：约 300-500mA @ 3.3V

## 十一、LAN / USB 双模式切换原理

### 模式切换逻辑

UZG-01 支持两种工作模式，通过 GPIO33 控制：

| 模式 | GPIO33 状态 | 红色 LED (GPIO12) | CC2652 连接对象 |
|-----|------------|------------------|----------------|
| **USB 模式** | HIGH (ON) | 亮 | CH340C（USB 串口） |
| **LAN 模式** | LOW (OFF) | 灭 | ESP32（UART → 网络） |

### 切换方式

1. **物理按键切换**：按一下 GPIO35 上的按钮，切换模式
2. **软件切换**：通过 ESP32 控制 GPIO33 电平

### 电路实现（推断）

使用 **模拟开关 / 多路复用器**（如 TS5A23157 或类似芯片）切换 CC2652 的 UART 线路：
- 一路连到 CH340C（USB）
- 一路连到 ESP32 的 UART（LAN 模式）

## 十二、Zigbee 固件更新流程（BSL 模式）

### 硬件连接

```
ESP32 GPIO16 ──→ CC2652 RESET_n
ESP32 GPIO32 ──→ CC2652 BSL (DIOx)
```

### 进入 BSL 模式的时序

1. 拉低 BSL（GPIO32 输出高，因为 inverted）
2. 等待 1 秒
3. 拉低 RESET（GPIO16 输出高，因为 inverted）
4. 等待 1 秒
5. 释放 RESET
6. 等待 4 秒（芯片启动进入 BSL）
7. 释放 BSL

### 固件更新工具

使用 `cc2538-bsl.py` 工具通过网络串口更新：

```bash
cc2538-bsl.py -p socket://<网关IP>:6638 -evw firmware.hex
```

## 十三、外围接口电路详解

### 1. USB-C 接口电路

| 信号 | 引脚 | 说明 |
|-----|------|------|
| VBUS | 5V | 电源输入（5V） |
| D+ | DP | USB 数据+ |
| D- | DM | USB 数据- |
| CC1/CC2 | CC | Type-C 配置通道 |
| GND | GND | 地 |

**周边器件**：
- ESD 保护二极管（USB 数据线上）
- VBUS 保险丝 / 自恢复保险丝
- 滤波电容（10uF + 100nF）

### 2. RJ45 网口电路

**连接路径**：
```
LAN8720A ──→ HX1188NLT 网络变压器 ──→ RJ45 网口
```

**网络变压器 (HX1188NLT)**：
- 百兆以太网隔离变压器
- 集成自耦变压器 + 共模电感
- 左侧（PHY 侧）：TX+/TX-、RX+/RX- 差分对
- 右侧（网口侧）：连接 RJ45 的 1/2、3/6 引脚

**RJ45 网口**：
- 内置 2 个状态 LED（LINK/ACT、SPEED）
- PoE 受电：4/5 (+)、7/8 (-) 或 1/2 (+)、3/6 (-)

### 3. CC2652P7 射频前端

**RF 输出路径**：
```
CC2652P7 RF_P/N ──→ 巴伦 (Balun) ──→ π 型匹配网络 ──→ SMA 天线座
```

**π 型匹配网络**（参考同系列设计）：
- 2 个电容 + 1 个电感组成
- 50Ω 阻抗匹配
- 谐波抑制

**天线接口**：
- SMA 母座（外接天线）
- 或 IPEX/U.FL 座（内置天线）

### 4. 自动下载电路（ESP32）

**实现方式**：双三极管 + CH340C 的 DTR/RTS

```
CH340C DTR ──→ Q1 三极管 ──→ ESP32 EN
CH340C RTS ──→ Q2 三极管 ──→ ESP32 GPIO0
```

**下载逻辑**：
- DTR 低 + RTS 高 → EN 低 + GPIO0 高 → 复位（运行模式）
- DTR 高 + RTS 低 → EN 高 + GPIO0 低 → 下载模式
- DTR 低 + RTS 低 → EN 低 + GPIO0 低 → 复位进入下载模式

### 5. 调试接口 / DIY Pinouts

产品页面提到 "DIY Pinouts are available"，可能包含：
- ESP32 串口引脚（TX/RX）
- CC2652 调试接口（JTAG/SWD）
- 备用 GPIO 引脚
- 电源测试点（3.3V、5V、GND）

### 6. 复位电路

**ESP32 复位**：
- 复位按键 (RESET) → EN 引脚
- CH340C 自动下载 → DTR → 三极管 → EN

**CC2652 复位**：
- ESP32 GPIO16 控制（inverted，低有效）
- BSL 模式由 GPIO32 控制
